# YMM4 EditAssist — 開発版 0.4.0

YMM4用の汎用ツールプラグインです。ボイス整理、台本配置、字幕・音量プリセット、編集チェック、素材検索・試聴、プレビュー診断を支援します。AI契約は不要です。ジャンルやキャラを固定しません。新機能の使い方・保護・制限は [編集機能ガイド](docs/EDITING.md) を参照してください。

ソースZIPと、ビルド済みの導入用 `.ymme` を別々に用意しています。使うだけならSDKの導入やビルドは不要です。編集支援の開発版です。プレビュー軽量化は別プラグインPreviewLiteで扱います。EditAssistは動画参照と編集支援を担当し、AI接続は未実装です。

2026-10-03更新。YMM4 4.56.1.1の実DLL、.NET SDK 10.0.401、Windows環境で検証しています。旧版0.1.0のプラグイン一覧への表示は利用者確認済みです。新版の実際のYMM4操作・音声生成・再生・動画出力は未確認です。合成タイムライン自動テストと実機操作は別です。確認範囲は `docs/VALIDATION.md` を参照してください。

## ビルド済み版を試す

1. YMM4を終了します。本番プロジェクトは別名のコピーを用意してください。
2. 旧EditAssistのフォルダを **user/pluginの外** へ退避してから、`EditAssist-0.4.0-net10.ymme` を対象YMM4へ導入します。plugin内で名前を変更して残すだけでは二重読込になります。他プラグインは変更しません。
3. YMM4を再起動し、ツールメニューの「EditAssist：一括編集・素材・診断」を開きます。
4. WAVを1個登録し、タグの保存、検索、試聴を確認します。その後、プロジェクトのコピーでドラッグを試してください。

一括編集は明示的な確認後に現在のタイムラインを変更し、事前に全シーンのymmpバックアップを作ります。元のymmpは自動で上書き保存しません。素材ファイル、本体設定、既存プラグイン設定は書き換えません。台本の音声生成はYMM4の設定済みエンジンを使い、クラウド音声を設定している場合はそのサービスの送信・課金・利用条件に従います。全環境への対応を保証するものではありません。

## 編集操作の追加機能（0.4.0）

- キャラ別レイヤー整理：ボイスをキャラごとの指定レイヤーへ一括移動。空欄はそのまま、バックアップと一回のUndo/Redo付き。
- セリフ・素材名の絞り込み：部分一致検索を既存の種類・キャラ・時刻・レイヤー条件と組み合わせて、選択・編集。
- 編集チェックから移動：結果一覧を選んで該当素材の開始位置へ移動。チェック後に素材を編集したら再チェックが必要。

詳しい操作・制限は [一括編集ガイド](docs/EDITING.md) を参照してください。PreviewLiteは変更していません。

## 動画参照・警告（0.3.0から）

「動画参照・警告」タブでファイル名1つと移動先フォルダーを指定し、確認後、全シーンの同名・分割クリップをまとめて再参照できます。事前バックアップと一括Undo/Redoに対応。元YMMPは自動上書きしません。

参照切れ・読み取り不可・以前とのパス／サイズ／更新日時の違いを一覧で警告します。「映像も確認」は先頭と使用開始位置の最大4か所を確認し、動画やプロキシを生成しません。全編の破損チェックではありません。詳細は [動画参照ガイド](docs/MEDIA-REFERENCES.md) を参照してください。PreviewLiteなしで動作します。

## ソースからビルドする場合

1. ZIPを**すべて展開**します。ZIPの中から直接起動しないでください。
2. [Microsoft公式の.NETダウンロード](https://dotnet.microsoft.com/download)から、YMM4の実行環境と同じ世代の **.NET SDK（Windows x64）** を導入します。v4.47.0.0以降は.NET 10が公式サンプルの対象です。SDKとRuntimeは別で、Runtimeだけではビルドできません。Visual Studioを使う場合も対応SDKが必要です。
3. `Build.cmd` をダブルクリックします。
4. 更新したYMM4の `YukkuriMovieMaker.exe` があるフォルダを入力します。exe自体のパスでも構いません。例：`C:\Tools\YMM4`。
5. スクリプトがYMM4の `runtimeconfig.json` を読み、必要な.NET世代を確認します。コアテスト、**そのYMM4本体のDLLを参照した**ビルド、画面生成と実APIのテストを順に実行します。初回は.NETの参照パック取得にインターネット接続が必要な場合があります。失敗したらパッケージ作成を停止します。
6. 成功すると `artifacts\EditAssist-0.4.0-net10.ymme` などができます。旧版を二重に残さないよう対象YMM4へ導入してください。
7. YMM4を再起動し、ツールメニューの「EditAssist：一括編集・素材・診断」を開きます。読み込みに失敗した場合は、プラグイン一覧やエラーメッセージで確認します。

最新版を主対象としていますが、初版のスクリプトは.NET 8 / 9 / 10の環境に合わせたビルドを選択できます。これはビルド設定の対応であり、全YMM4版で動作確認済みという意味ではありません。.NET 7以前や11以降を検出した場合は停止します。

`Build.cmd` は、そのビルド処理だけに適用する `-ExecutionPolicy Bypass` でPowerShellを実行します。PC全体の実行ポリシーやYMM4設定は変更しません。

ポータブルSDKは `-DotnetPath "C:\Tools\dotnet\dotnet.exe"` で指定できます。複数世代のSDKがある場合、選択中のSDKとYMM4の.NET世代が一致しなければ停止します。自動テストは見えるウィンドウを開かず、YMM4へのインストールや本番プロジェクトの変更を行いません。

### 指定したYMM4へ直接配置する方法（任意）

`.ymme`の導入先が曖昧な場合は、YMM4を終了してから、展開フォルダでPowerShellを開き、次を実行できます。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1 -Ymm4Directory "C:\Tools\YMM4" -Install
```

この方法は `user\plugin\EditAssist` に自作DLL2個を配置します。同じフォルダは上書き前に `user\EditAssistBackups` へコピーします。YMM4実行中や別フォルダにEditAssistがある場合は停止します。`.ymme`経由と直接配置を二重に行わないでください。

## 素材管理・診断（旧版からの機能）

| 機能 | 内容 |
|---|---|
| 素材登録 | フォルダ・ファイルから音声、画像、動画を登録。サブフォルダも走査 |
| 検索 | 名前、元ファイル名、擬音・説明、タグ、種類、お気に入りで絞り込み |
| 場面検索 | 驚き、失敗、成功、登場、緊張、場面転換、説明。ローカル辞書による検索 |
| 情報編集 | 表示名、タグ、説明、配布元ページURL、利用条件のメモ、★を保存 |
| 音声試聴 | WindowsのMediaPlayerで再生・停止・音量調整 |
| 受け渡し | Windowsの標準ファイルドラッグ形式、パスコピー、素材フォルダを開く |
| 欠損確認 | 元ファイルが見つからない・アクセスできない登録を表示。自動削除はしない |
| 比較記録 | YMM4版、.NET、OS、ライブラリ情報、10秒のCPU区間平均と終了時メモリを記録 |
| 読込設定の確認 | 保存済みの動画読込順とProxyForge 1.xの既知設定を読み取り、確認候補を表示 |
| 診断保存 | 手入力の条件・症状と計測値をMarkdownで保存 |

場面辞書はAIによる動画解析ではありません。例えば「失敗」を選ぶと「ずっこけ」「チーン」「落胆」などの名前・タグ・説明を持つ素材を探します。名前が数字だけの素材は、表示名やタグを自分で付ける必要があります。キーワードは空白区切りでAND条件、同じ場面の別表現はOR条件です。画像・動画は初版では検索と受け渡しのみです。

音声・映像を走査時にデコードしません。ディスクの走査は別スレッドで行い、中止できます。1回の走査は2万件までで、上限に達した場合は表示します。権限のないフォルダ、ディレクトリリンクは対象外です。ネットワークドライブではOSのファイルアクセスが戻るまで中止が遅れる場合があります。

素材を追加しても元ファイルをコピー・改名・削除しません。元ファイルを移動すると登録先が欠損するので再登録してください。「ライブラリから外す」は登録解除です。元フォルダを再スキャンすると再登録されます。

試聴できる形式はWindowsの再生対応に依存します。最初はWAV・MP3で確認してください。素材管理のドラッグは標準ファイルドロップです。新版の「タイムライン編集」は実YMM4の接続APIを使用します。実際の受け取り・編集・出力はコピーで検証してください。

## 素材の入手と保存

効果音ラボ・OtoLogicへのボタンは配布ページをブラウザで開きます。音源の検索サイト内検索・自動ダウンロード・一括取得は実装していません。素材の利用条件を確認して自分でダウンロードし、登録してください。第三者の音源を同梱していません。

メタデータは `%LOCALAPPDATA%\YMM4EditAssist\catalog.json` に保存します。保存成功ごとに直前の内容を `catalog.json.bak` に残します。作業用JSONの置換は一時ファイルを使って行います。複数のYMM4から同じ素材データを同時に書き換えないよう、ファイルロックを使います。2つ目では素材管理が開けないことがあります。

壊れたJSONや未対応のデータ形式を検出した場合は、新しい空のデータで上書きしません。YMM4を閉じ、`catalog.json` と `.bak` を別の場所にコピーして保存したうえで、正しいバックアップを `catalog.json` に戻してください。バックアップがない場合は壊れたファイルを退避してから起動すれば新規登録を開始できます。

## プレビュー不調の比較

この初版は **診断を補助するものです。デコード・標準プレビュー・プロキシ処理を修正しません。GPU使用率や実描画FPSを測りません。**

今のYMM4と旧版を別フォルダに置き、同じ素材・同じ区間・同じ設定で比較してください。本番プロジェクトはコピーして使います。新版で保存したプロジェクトを旧版でも読めるとは限りません。

1. 素材1本のみのコピーで不調が出るか確認。
2. プロキシ生成が終わった状態で、使用プラグイン名・版・優先順位を確認して比較。
3. エフェクトや立ち絵を加えた場合と比較。
4. YMM4公式FAQの読込プラグイン優先順位、ハードウェアデコードの対処候補を、一つずつ試して記録。設定変更後は指定どおり再起動。
5. 「プレビュー比較記録」タブに条件を記入し、YMM4で再生してから10秒計測。
6. 観察した症状と時刻を入力し、「最後の記録に症状を反映」を押す。
7. 比較記録を保存。再起動で計測履歴は消えるので、終了前に保存。

CPUはYMM4のプロセス全体の値です。全論理CPUで100%になる換算で、タスクマネージャーの表示と条件によって差が出ます。作業メモリと管理メモリは計測終了時の値で、ピーク値ではありません。プロキシ使用・デコード設定は手入力です。計測中はこのプラグインで素材走査や試聴を始められないようにしています。他プラグインの生成処理や録画等も比較条件を揃えてください。

レポートの自動取得欄には素材パス、設定パス、APIキーを入れません。自由記述に書いた情報はそのまま含まれるので、共有前に確認してください。読み込まれたライブラリ一覧は、YMM4の有効プラグイン一覧や優先順位の取得結果ではありません。

「保存された動画読み込み設定」は別欄です。今動いているYMM4の版別設定フォルダから、既知の項目だけを読みます。ProxyForge 1.xの設定形式を対象とし、形式が違う場合は不明です。前に別の読込プラグインがある、プロキシが無効などの確認候補を示しますが、実際にどの素材がプロキシで再生されているかは判定しません。未保存の設定変更は反映されません。設定の変更・削除・キャッシュ整理は行いません。

## 削除・戻し方

YMM4を終了し、導入したEditAssistのプラグインフォルダを別の場所へ退避します。直接配置した場合は `user\plugin\EditAssist` です。`.ymme`で導入した場合は実際の導入先を確認してください。素材メタデータは別保存なので残ります。DLLの以前のバックアップを使う場合も、別のプラグインフォルダに複製したままにせず、一つの版だけ配置します。

## 開発構成

- `src/EditAssist.Core`：検索、走査、保存、プロセスの比較記録。YMM4とWPFに非依存。
- `src/EditAssist.Plugin`：YMM4ツールの入口とWPF画面。YMM4参照DLLは同梱しない。
- `tests/EditAssist.CoreChecks`：検索、メタデータ保持、取消、保存、破損時保護、診断記録を確認する実行型テスト。外部のテストパッケージは不要。
- `tests/EditAssist.WindowsChecks`：実YMM4インターフェース、ツールの生成情報、WPF画面と配置、通知を確認するウィンドウ非表示のテスト。YMM4内での操作確認とは別。
- `Build.ps1` / `Build.cmd`：実環境に合わせたビルド、テスト、`.ymme`作成。
- `PackageSource.ps1`：ソースだけをZIPにまとめる。bin/obj/artifacts、YMM4本体、個人設定は含めない。
- `PublishGitHub.ps1`：明示設定した別フォルダーのGitリポジトリへソースだけを同期し、コミット・送信・到達確認。[設定と停止条件](docs/GITHUB.md)。
- `docs/WINDOWS-CHECKLIST.md`：初回のYMM4実機確認。
- `docs/VALIDATION.md`：確認済みと未確認を分けた記録。

公開ライセンスと一般公開先は未決定です。第三者コードのコピーやYMM4本体の再配布を前提にしていません。公開前に対応版、実機テスト、ライセンスを確定してください。
