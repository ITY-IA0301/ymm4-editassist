# 0.4.0 実際のYMM4での確認

本番プロジェクトを別名にしたコピーで行います。自動テスト296項目は通過していますが、以下の実機操作は未実施です。版・音声エンジン・手順・最初のエラーを記録してください。

## 更新

1. コピーを保存し、YMM4を終了。
2. 旧EditAssistフォルダをuser/pluginの外へ退避。他プラグインは変更しない。
3. 0.4.0のymmeを導入し、再起動。
4. 「EditAssist：一括編集・素材・診断」が一つだけ表示され、開閉／再度開くこと。
5. 「タイムライン一括編集」で、開いたタイムライン名・FPSが表示されること。

## 小さいコピーでの編集

- ボイス2個、間に画像・動画・BGMを置き、ボイスのみの条件選択で対象が2個になる。
- キャラ別／時刻・レイヤー範囲が合う。数字グループの手動ドラッグは関連素材追従に注意。
- レイヤー変更を確認しただけでは動かない。実行時に確認とバックアップが出る。
- ボイスのみが移動し、開始・長さ・セリフ・分割音声開始位置は不変。字幕・音量・合成順の移動先効果を確認。
- 一回のYMM4「元に戻す」で全件戻り、やり直しで再適用。
- 直前の変更を復元できる。その後に別編集した場合は拒否。
- ロック・数字グループ・グループ制御への影響は停止。移動先重なりは注意許可が必要。
- プレビュー後にタイムライン／キャラ設定を変えると実行拒否。
- 生成済み未分割ボイスの尺が音声＋追加時間に一致。分割・速度アニメーションは除外。
- 後続追従は明示範囲のみ。境界をまたぐ長い動画やロック／グループで停止。
- 字幕／音量のプリセットで空欄は保持、キャラ共通設定は不変。継承書式・字幕可視状態を確認。
- アニメーションがある該当項目は明示許可なしで停止。

## 検索・キャラ別整理・チェックから移動

- セリフ検索で画像・動画が除外され、種類・キャラ・時刻・レイヤー条件を同時に満たす。
- キャラ別一覧は現在の条件のボイスだけ。空欄のキャラは動かず、入力変更で確認が無効になる。
- 複数キャラを指定レイヤーへ一括移動。画像・動画・開始・長さ・分割オフセットは不変。バックアップと一操作Undo/Redoを確認。
- ロック・グループ・移動先の範囲外で実行不可。重なり警告を確認。
- 編集チェックの結果を選び、対象一つと再生位置だけが変わる。複数結果への移動を繰り返せる。
- 素材を編集した後は古い一覧で移動できず、再チェックが必要。

## 動画参照・警告

- PreviewLiteを導入していなくても、EditAssistの「動画参照・警告」が開く。
- 複数シーンで分割した同名動画を指定し、移動先・対象件数の確認だけでは参照が変わらない。
- 実行前のバックアップ、動画全件の再参照、カット位置・長さ・レイヤー・効果の保持を確認。
- 一回のYMM4「元に戻す」で全シーンの対象を戻せる。元YMMPは通常保存するまで変わらない。
- 不足・空・読取不可・同名候補重複・ロックでは安全に停止／警告。
- 映像検査と取消、参照変更の警告、明示的な比較基準更新を確認。全編の正常保証と扱わない。
- 参照タブを閉じると15秒確認が停止。PreviewLiteに参照タブがなく、軽量化だけを担当する。

## 台本

YMM4単体で音声生成できるキャラを使います。クラウド音声なら送信・課金・利用条件を確認します。

- 2行のUTF-8 CSV／TSVを解析。別名キャラを登録済みキャラへ割当。
- 音声生成完了までは追加されず、配置プレビュー後の実行で全件追加。
- 音声長、キャラ、レイヤー、セリフ間隔、字幕、実再生を確認。
- 未割当・生成失敗・途中中止で部分追加されない。
- 一括追加のUndo/Redo／直前復元ができる。
- キャラの追加アイテムテンプレートや別立ち絵を自動追加しないことを確認。

## 保存・チェック・既存機能

- 欠損素材／重なり／閾値以上の空白を報告し、勝手に修正・削除しない。
- バックアップを別名で開き、全シーン、キャラ、第三者効果、音声・素材参照を確認。
- プロジェクト別名保存は既存ファイルを上書きしない。
- 元プロジェクトのファイル更新日時が、ツールだけで変わらない。
- 素材登録／タグ保存／再走査／試聴／停止／ドラッグ／再起動後の情報保持。
- 比較診断はCPU・メモリと手入力を記録。FPS・GPU・実プロキシ状態の測定ではない。
- 通常の編集・保存・動画出力・音声同期・最終画質を確認。
- 不具合時はYMM4を閉じ、旧版を一つだけ戻せる。素材情報を保持。

バックアップ／台本／レポートにはパスや個人情報が入り得ます。共有前に確認してください。バックアップは自動削除せず、利用者が容量を管理します。
