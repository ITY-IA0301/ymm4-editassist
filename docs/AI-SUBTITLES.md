# ChatGPT支援と字幕調整（開発版0.5.0）

字幕調整はAI未接続でも使えます。ChatGPTで作った台本は既存の台本編集へ渡し、音声と配置を確認した後、同じ字幕調整を適用できます。動画ジャンル・キャラ・AI契約を基本機能の必須条件にしません。

## 字幕調整

1. プロジェクトのコピーを開き、YMM4で対象のボイスまたはテキストを選びます。
2. EditAssistの「字幕調整」タブを開きます。
3. 次のスイッチを個別に設定します。初期状態はすべてOFFです。

| 設定 | ONの動作 | OFFの動作 |
| --- | --- | --- |
| 文章量を調整 | 1表示の文字数・最大行数・領域に合わせてページを分割 | 1つの字幕として扱う |
| 文字サイズを調整 | 最小～最大サイズ内で領域に収める | 元の固定文字サイズを保持 |
| 改行を調整 | 幅と句読点を考慮して明示的な改行を入れる | 自動で改行を追加しない。元の明示改行は保持 |

4. 字幕領域の幅・高さ・内側余白、中心X/Y、空いた字幕レイヤーを指定します。X/Yは動画画面の中心を原点とします。初期値は1920×1080を想定しているので、別解像度では調整してください。
5. 「変更プレビュー」で文章・サイズ・開始フレーム・長さ・警告を確認します。
6. 確認チェックを入れて適用します。全シーンのYMMPバックアップを作成してから一括変更します。YMM4のUndo/Redoか「直前の変更を復元」で戻せます。

ボイスのSerif・音声ファイル・開始・長さ・音声レイヤーは変更しません。元のボイス字幕を非表示にし、独立したTextItemへ置き換えます。元のTextItemは独立した調整後TextItemへ置換します。既存音声の切り貼り・音声再生成は行いません。

分割字幕の切替時刻は、テキストの量による比例配分です。音素時刻や発話を解析していないため、音声を聞いて切替位置を確認してください。フレーム数よりページ数が多い場合は拒否します。文字・絵文字・結合文字を切り捨てません。

WPFでフォント・太字・斜体・行間・字間の文字領域を計測します。判定は目安で、YMM4の縁取り、装飾、エフェクト、別レンダラーによる差は含めません。内側余白を取って、YMM4上の実映像で確認してください。配置は指定領域の中心・拡大率100%・回転0へ揃えます。ページごとに継承したフェード・エフェクトは開始し直されます。複雑な演出は手動調整が必要です。

ロック、グループ、非表示、字幕非表示、分割音声、速度／文字サイズ／字間／行間のアニメーション、部分装飾、一文字ずつ表示する字幕は自動調整の対象外です。重なりやグループ制御範囲のある配置先、同時に重なる複数字幕は適用を拒否します。キャラごとに別レイヤーで処理してください。設定を変えると古い変更プレビューは無効になります。

「設定を保存／読み込む」でスイッチ・文字数・行数・サイズ範囲・領域・位置・レイヤーをJSONで保存できます。

## ChatGPTへコピーして受け渡す

1. 「ChatGPT支援」で依頼・キャラ設定・下書きを入力します。YMM4のキャラ名と選択ボイスのセリフを取り込むボタンも使えます。
2. 必要なら「登録素材の候補情報を含める」をONにし、検索語で候補を絞ります。名前・種類・タグ・説明・IDを最大200件含めます。素材パス・動画・音源・認証情報は自動では渡しません。入力した文章の内容はそのまま依頼に含まれます。
3. 「依頼文を作成」で内容を確認し、「依頼文をコピー」してChatGPTに貼り付けます。
4. JSONの返答を「返答の確認」へ貼り付け、読み込みます。JSONファイルの読み込みにも対応します。
5. 台本・素材候補を確認し、「台本編集へ渡す」を押します。CSV保存も可能です。
6. 既存の台本取り込みで解析・キャラ割当・音声生成・配置プレビューを行います。字幕調整は、その後に対象ボイスを選んで適用してください。

台本作成・修正・短縮と登録素材の候補提示を初期機能とします。対象尺は文章上の目安で、音声生成後の実長で確認します。AIによる動画解析、SE/BGMの自動配置、自然言語からの任意のタイムライン編集、他社AI、OpenAI API直接接続はこの版にはありません。

## Codex CLIで自動生成

Windowsに公式Codex CLIを別途導入し、`codex login`でChatGPTログインを済ませてください。`--ignore-user-config`、`--ephemeral`、`--output-schema`に対応したCLIが必要です。`codex login status`でログイン方法を確認できます。

「CLIを選択」で実行ファイル（codex.exeまたはnpmのcodex.cmd）を選びます。モデルは任意指定できます。空欄ならCLI標準です。依頼文を作成し、送信内容・利用枠使用のチェックを入れ、「Codex経由で生成」を押します。ChatGPTログイン方式を指定し、APIキー環境変数を子プロセスへ渡しません。普段のユーザー設定を読み込まず、シェル・検索を無効にしたread-onlyモードで実行します。個人用のローカル連携であり、未認証の第三者に公開するサーバーではありません。

認証情報はCodexに任せ、プラグインはauth.jsonやAPIキーを読みません。依頼は標準入力で渡し、モデル名を検証し、CLIの出力をスキーマとローカル検証で確認します。生成結果でコマンドを実行したり、任意のプロジェクトプロパティを書き換えたりしません。

「AI生成を中止」またはツール終了でCLIプロセスツリーを停止します。タイムアウトは5分です。失敗・キャンセルで台本やタイムラインを自動変更しません。生成にはCodexの利用枠を使います。環境や利用枠の状態によって失敗する場合はコピー方式を使えます。

素材候補は既存IDだけを受け付けます。候補を選び「ライブラリで開く」から通常の試聴・受け渡しを利用できます。素材を外部サイトから自動取得しません。

## 接続を追加する場合

`IAiProvider`を通じて、今後別の接続先を追加できます。共通のAiRequest・AiResult・検証・CSV・字幕処理を利用する構成です。CLI連携の実APIログイン・生成はこの開発環境では未検証です。
