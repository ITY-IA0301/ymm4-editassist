# 語尾・話し方の指定（0.5.1）

ChatGPT支援に「ゆっくりの語尾・話し方」を追加。

- 手動指定：キャラ名、一人称、語尾、口調、役割、避けたい表現を自由に記入。個別にON/OFF。
- 参考台本：キャラ,セリフの2列CSV/TSVまたは選択ボイスから、キャラごとの文末頻度と例文をローカル抽出。結果は編集可能、個別にON/OFF。
- 両方有効なら手動指定優先。抽出結果は生成プロンプトの参考に使う。AIモデルの重み更新ではない。
- 設定はJSONに保存・読み込み可能。抽出し直すと既存の抽出結果を置き換える。
- 抽出は末尾最大4文字の単純集計。文法的な語尾や性格・ボケとツッコミの役割を自動確定しない。参考例文をAIが読み、手動設定と合わせて話し方を提案する。
- 参考例文もON時はChatGPT/Codexへ送信する。依頼文のプレビューで確認できる。

例：霊夢：一人称は私。ボケ担当。自然なくだけた口調。語尾は～ね、～よを使うが毎回固定しない。
魔理沙：一人称は私。ツッコミ担当。～だぜ、～だなを使い、強い罵倒は避ける。
