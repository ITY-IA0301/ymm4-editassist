# EditAssist：動画参照・警告

ツール「EditAssist：一括編集・素材・診断」内の機能です。PreviewLiteの導入は不要です。

## 動画参照の一括修復

「動画参照・警告」タブを開きます。選択中シーンだけでなく、**プロジェクトの全シーンの動画クリップ**を対象にします。

1. 一覧から対象を選ぶか、拡張子を含む動画ファイル名1つを入力します。
2. 移動先フォルダーを入力・選択します。録画なら `D:\MinecraftArchive`、リプレイなら `D:\Minecraftreplay` などです。
3. 「変更内容を確認」を押します。分割クリップ数・シーン数・新しい参照先が表示されます。
4. 確認して「バックアップして全件再参照」を押し、確認ダイアログで実行します。
5. YMM4の通常のプロジェクト保存を行ってください。この機能自体は、元のYMMPをディスク上で自動上書きしません。

同じファイル名を参照する全クリップのFilePathだけを変更します。カット位置・長さ・レイヤー・音声・映像効果・トランジションなどは保持します。
画像や音声素材は対象外です。ロックされた対象がある場合は全件停止します。
同名候補が複数なら自動選択せず停止します。検索先を絞るか「移動先動画から指定」を使ってください。
同名でも動画内容が同じとは保証できません。必ず移動先を確認してください。

確認後にプロジェクトが編集された場合、動画がなくなった／更新された場合、バックアップに失敗した場合は変更しません。
YMM4の「元に戻す」で全件を一括復元できます。
変更前の全シーン・キャラを含む復旧用YMMPは `%LOCALAPPDATA%\YMM4EditAssist\backups` に保存します。
復旧用YMMPは画面配置・各ツールの状態を含みません。未保存の編集内容も含めて、プロジェクトの編集データを復旧するためのものです。

## 参照切れ・変更・映像読み込みの警告

- 初回に参照パス・ファイルサイズ・更新日時を記録します。以後、参照先がない・空・読み取れない・以前と参照先やサイズ／更新日時が違う場合に一覧で警告します。
- オフライン属性のあるクラウド上のみのファイルは自動取得せず、ローカルへの取得が必要と警告します。
- 「この画面を開いている間、15秒ごとに…」がONなら、参照タブを表示している間は軽い確認を繰り返します。閉じている間やYMM4終了後は監視しません。
- 意図した移動・置換を確認したら「現在の参照を比較基準に保存」で変更警告の基準を更新できます。読み込み異常の警告を正常扱いにはしません。
- 「映像も確認（数か所）」では、YMM4同梱のffprobe／ffmpegを別の非表示プロセスで使用します。プロキシ読み込みプラグインを呼び出さず、新しい動画やプロキシを生成しません。
- 先頭と、分割クリップで使っている開始位置から最大3か所を選んで、それぞれ1フレームだけ読み込みます。1ファイル合計20秒で打ち切り、中止もできます。
- 空ファイル・動画情報が読めない・映像がない・サンプル映像が読めない・使用開始位置が動画の長さを超える場合を警告します。時間切れや検査部品の不足は「未確認」と区別します。

**簡易確認の「確認済み」は映像全体の正常判定ではありません。** 映像検査も全編の破損チェック・音声検査・HighSpeedなど別リーダーでの動作保証ではありません。
ループ素材の開始位置が元動画の長さを超える場合は、映像サンプル警告の内容を個別に確認してください。
サイズと更新日時を変えずに中身だけ置換したファイルは簡易比較では検出できません。完全な動画ハッシュは取りません。
比較用記録は `%LOCALAPPDATA%\YMM4EditAssist\reference-history` に保存し、全シーンIDから識別します。複製したプロジェクトは同じ比較用記録を使う場合があります。


## 旧PreviewLite版との移行

旧PreviewLite 0.2.0の比較基準は移行後の初回に読み取り、新しい保存先へ記録します。旧バックアップは `%LOCALAPPDATA%\YMM4PreviewLite\backups` に残し、削除しません。新規バックアップはEditAssist側に保存します。

動画参照機能はYMM4 4.56.1.1 / .NET 10で検証。実画面での操作・全編検査・別読込プラグイン互換性は未検証です。
