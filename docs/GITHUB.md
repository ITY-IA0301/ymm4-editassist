# GitHubへの自動登録

これはEditAssistのソース管理用です。PreviewLiteは独立したプラグインとして扱い、同じDLLへまとめません。現在のGitHub保管では`plugins/PreviewLite`に最新版のソース、`archive`に両プラグインの各過去版を分けて保存します。下記の自動登録処理はEditAssistのソースだけが対象で、PreviewLiteや過去版の自動更新は行いません。

## 動作

`Build.ps1`がテスト・ビルド・パッケージ作成に成功した後、ローカル設定が有効な場合だけ、ソースの同期・コミット・GitHubへの送信・コミット番号の確認を行います。常時監視や定期送信ではありません。YMM4起動時や編集作業中には実行しません。

転送対象は、指定されたルートの開発ファイルと`src`・`tests`・`docs`内のコード・説明資料だけです。動画、YMMP、バックアップ、YMM4本体、生成DLL、ビルド成果物、個人設定、チャット履歴、SDKは送信しません。未知の拡張子は送信せず停止します。`.ymme`のRelease公開やリポジトリの公開範囲変更は行いません。

## 設定

GitHub Desktopなどで作成・接続済みの、ソースとは別のGitリポジトリを使います。Gitが利用でき、利用者名・メールとGitHubへの認証が設定されている必要があります。公開ライセンスと実機確認が未確定のため、最初は非公開を推奨します。

ソースの`Build.ps1`と同じフォルダーに`GitHubPublish.local.json`を作ります。このファイルはGitとソースZIPから除外されます。以下の場所・URLを自分のものに置き換えてください。URLにトークンやパスワードを書かないでください。

```json
{
  "Enabled": true,
  "RepositoryDirectory": "C:\\Projects\\GitHub\\ymm4-editassist",
  "ExpectedRemote": "https://github.com/YOUR-ACCOUNT/ymm4-editassist.git",
  "Branch": "main"
}
```

停止するには`Enabled`を`false`にするか、ローカル設定ファイルを外します。配布ZIPからのビルドではこの設定がないため自動送信しません。

検証済みソースを手動で登録する場合：

```powershell
.\PublishGitHub.ps1 -RepositoryDirectory 'C:\Projects\GitHub\ymm4-editassist' -ExpectedRemote 'https://github.com/YOUR-ACCOUNT/ymm4-editassist.git'
```

## 保護・停止条件

- リポジトリに未コミットの変更がある場合は上書きせず停止します。
- 別の人やGitHub上の更新がローカル履歴に含まれない場合は、同期前に停止します。自動マージや強制送信はしません。
- 前回同期後にリポジトリ側のソースが独立に変更・削除された場合、またはソースが削除された場合は停止します。変更内容を手動で照合してください。
- 初回から内容の異なるファイルがある場合も上書きしません。別の空のリポジトリを使うか、手動で内容を合わせてください。
- 接続先変更、枝の相違、リンク先への転送、不明ファイル、認証エラーは停止します。
- 送信失敗でもローカルのファイル・コミットは残します。問題を解消して同じ設定で再実行すると送信を再試行できます。ビルド後の送信失敗はビルド全体の終了コードも失敗になりますが、作成した`.ymme`は残ります。

同期基準のハッシュは転送先の`.git/editassist-publish-state.json`へ保存し、GitHubへは送信しません。基準は安全確認のための記録です。内容の確認を省くために消さないでください。

`git`の安全なディレクトリ設定は指定したリポジトリへの各呼び出しだけに限定し、システム全体やすべてのフォルダーを信頼する設定にはしません。
