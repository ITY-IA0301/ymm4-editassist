# EditAssist OBS Markers 0.1.0

Minecraftなどの録画中に、キーで「見せ場・説明・完成」の目印を残すOBS用Luaスクリプトです。YMM4を起動しておく必要はありません。Pythonの導入やビルドも不要です。

この版はマークの記録までです。EditAssistの画面への読み込み、自動解析、カット、台本生成は今後の機能です。

## 導入

1. `editassist-markers.lua`を保存しておくフォルダーに置きます。
2. OBSで「ツール → スクリプト」を開き、「＋」からLuaファイルを追加します。
3. 「設定 → ホットキー」で「EditAssist」を検索し、使いたい操作にキーを割り当てます。
4. 新しく録画を開始します。以後は録画開始・停止に合わせて記録が動作します。

| 操作名 | 動作 |
|---|---|
| EditAssist：見せ場を記録 | 面白い出来事などに追加 |
| EditAssist：説明場面を記録 | 建築の意図など、説明したい場面に追加 |
| EditAssist：完成場面を記録 | 完成披露や成果に追加 |
| EditAssist：直前のマークを取り消す | 今回の録画で最後に付けたマークを削除 |

キーは初期状態では未割り当てです。他の操作と重ならない組み合わせを選んでください。例：Ctrl＋Shift＋F9/F10/F11。OBSのホットキーをバックグラウンドでも有効にする設定で使います。ゲーム中に受け取れるかは、最初に短い録画で確認してください。

設定したキーはOBSのスクリプト設定に保存されます。長押ししても、離すまで同じマークを連続追加しません。録画していないときは記録しません。一時停止中は新しいマークを追加せず、取り消しはできます。

録画中にスクリプトを追加・再読み込みした場合、次の録画開始から記録します。読み込み後もLuaファイルを移動・削除しないでください。複製した同じスクリプトを二重に追加しないでください。

## 保存先と使い方

初期設定では、最初の録画ファイルと同じフォルダーに保存します。

```text
2026-10-07_13-00-00.mp4
2026-10-07_13-00-00.mp4.editassist-<記録ID>.markers.json
```

動画本体は変更しません。JSONには動画パス、時刻、種別、前後の確認範囲を記録します。OBSによるファイル分割は一つの記録にまとめ、マークごとに対象ファイルとファイル内の時刻を持ちます。分割ファイル一式とJSONを一緒に保管してください。

再多重化・動画移動・改名後は元のパスが記録に残ります。今後の読み込み側で対応付ける必要があります。保存先変更は次の録画から適用します。

「ツール → スクリプト」の右側で前後の確認範囲を変更できます。初期値は前30秒・後15秒です。確認範囲が分割境界をまたぐ場合は、録画全体の時刻と分割一覧で前の動画も特定できます。録画終端を超える確認範囲は、読み込み側で動画の長さまでに制限します。

別の保存先を指定する場合は既存の書き込み可能なフォルダーを選んでください。日本語パスを扱うため、保存にはOBSのUTF-8ファイルAPIを使用しています。

追加・取り消し・分割・録画終了の都度保存します。一時ファイルによる安全な保存と直前の内容の`.bak`を使います。保存失敗時はOBSログに警告し、メモリに保持して1秒ごとに再試行します。録画終了後もOBSを閉じるまでは再試行します。保存できていないままOBSを終了するとメモリ上の記録が失われるので、保存エラー時は権限・空き容量を確認してください。

## 時刻の精度

**時刻は見せ場を探すための目安です。フレーム単位のカット位置ではありません。**

OBSの録画開始通知を基準に単調増加の時計で計測し、一時停止時間を除外します。分割は出力の`file_changed`通知で追跡します。エンコードの待ち時間、通知の遅れ、キーフレーム境界により実動画との差があり得ます。マークの前後を再生して使用位置を決めてください。JSONにも`timing_is_approximate: true`を付けます。

標準録画出力が対象です。独自FFmpeg出力、外部録画プラグイン、同時複数録画、録画中のプロファイル切替は未確認です。パスを取得できない出力では、誤った動画に記録せず警告します。

## 最初の動作確認

1. 画面に秒数の分かる時計などを出し、短い録画を開始します。
2. 10秒付近で「見せ場」、20秒付近で「説明」を押します。
3. 取り消し、もう一度「説明」を押します。長押しで増え続けないことも確認します。
4. 10秒程度一時停止して再開し、「完成」を押します。
5. 録画停止後、動画の隣の`.markers.json`をテキストエディターで開きます。停止時間が動画位置に加算されていないことを確認します。
6. 分割を使う場合は別途確認し、`segments`とマークの`video_file`が切り替わることを確認します。
7. OBS再起動後もキー設定が残り、ゲーム操作中にも記録できることを確認します。

状況はOBSの「ヘルプ → ログファイル」またはスクリプトログで確認できます。

## 検証範囲

LuaJITで実スクリプトを読み込み、OBS APIの代替実装を使って通常録画、長押し、一時停止、分割、取り消し、10本の連続録画、再読み込み、保存失敗と再試行、参照の解放を自動検証します。結果はGitHub Actionsと配布物の`OBS-MARKER-CHECKS.log`で確認できます。

**Windows上の実OBS・実ゲーム・実エンコードでの動作は未検証です。** 上記の短い録画で確認してください。YMM4プラグインの版は変更しません。

開発用テストはリポジトリのルートで`python tests/obs_markers_checks.py`。テストにだけ`lupa`が必要です。
