# OBS RecordMarks 0.1.0

OBSの録画中にキーを押して、見せ場・説明に使う場面・完成などの時刻を記録する独立したLua拡張です。EditAssistやYMM4を起動せずに使えます。キーは任意の補助で、押し忘れた出来事を自動検出する機能はありません。

## 導入

1. このZIPを、削除・移動しないフォルダーへ展開してください。
2. OBS Studioの「ツール → スクリプト」を開きます。
3. 左下の「＋」から `record-marks.lua` を追加します。
4. OBSの「設定 → ホットキー」で `RecordMarks` と検索し、必要なキーを割り当てます。すべて割り当てる必要はありません。
5. 必要に応じてスクリプト画面で、前後を確認する秒数や録画テーマを設定します。

対象は **OBS Studio 29以降の通常のファイル録画**です。Windowsを主な対象として設計しています。Python、WebSocket、APIキーの設定は不要です。現時点では実際のWindows/OBSでの動作確認は未実施です。最初に短いテスト録画で確認してください。

## 使い方

OBSで録画を開始すると、記録も自動的に開始します。ゲーム中に設定したキーを押すと、その時刻を保存します。「ツール → スクリプト」のボタンでも記録できます。

| 操作 | 記録する種類 |
|---|---|
| RecordMarks: 見せ場 | ミス、遭遇、面白い出来事など |
| RecordMarks: 説明 | 建築の工夫や作業の説明に使う場面 |
| RecordMarks: 完成 | 完成した建物や成果を見せる場面 |
| RecordMarks: メモ | その他の場面 |
| RecordMarks: 直前のマークを取り消す | このスクリプトが現在保持している録画の最後のマークを取り消す |

初期値は **前30秒・後15秒**です。これは後で確認する範囲を指定する設定で、動画を切り出す操作ではありません。キーの重複入力は0.35秒以内を抑制します。

メモはスクリプト画面に入力し、以後のマークへ添付できます。録画テーマは次の録画から適用します。記録成功・失敗はスクリプトのログへ表示します。設定画面の「状態を更新」で最新の状態が表示されます。画面や録画音声へ通知を追加しない設計です。

録画が一時停止中の場合はマークしません。時刻を録画済みフレーム数から計算するので、一時停止した時間を時刻に加算しません。

## 保存されるファイル

動画が `録画01.mkv` の場合、同じフォルダーに次のファイルを作ります。

- `録画01.mkv.markers.json`：そのファイルに付けたマーク。
- `録画01.mkv.marker-session.json`：分割されたファイルを含めた録画全体の一覧。
- `.bak`：直前に保存したJSONのバックアップ。

キーを押したとき、分割されたとき、録画を終了したときに保存します。JSONはOBSの保存APIで一時ファイルとバックアップを利用して保存します。同名の記録が既にある場合は、セッションIDなどの付いた別名で保存します。

録画動画は変更しません。AIや外部サーバーへの送信もありません。JSONには動画の保存パスと入力したメモが含まれます。

## マークを見る

1. 同梱の `marker-viewer.html` をブラウザで開きます。
2. `.markers.json` または `.marker-session.json` を選びます。録画全体のファイルを選ぶと、複数に分割した録画をまとめて確認できます。
3. 対応する動画ファイルを選びます。複数選択できます。
4. 候補をクリックすると、設定した前後の範囲を再生します。「マーク位置へ」でその時刻に移動できます。

ファイル名・メモで検索し、種類で絞り込みできます。表示中の一覧をExcelで開きやすいUTF-8 BOM付きCSVへ保存できます。このCSVはマーク一覧で、YMM4に取り込む台本CSVではありません。

ブラウザは、ファイル選択で許可した動画だけを読み込みます。JSONに書かれた絶対パスから動画を勝手に開くことはできません。同じ名前の動画を複数選ぶと紛らわしいため、対象動画だけを選び直す表示を出します。

MKV・AV1などの対応はブラウザに依存します。再生できない場合はOBSでMP4へ再多重化するか、外部プレーヤーで一覧の時刻へ移動してください。再多重化した動画を選ぶと、拡張子以外の名前が一致し、候補が一つだけの場合は関連付けます。再多重化で映像コーデックは変わらないため、MP4にしても再生できない場合があります。

同じ録画の全体記録と個別記録をまとめて選んだ場合は、全体記録を優先します。古い個別記録から取り消し済みマークが復活しないためです。複数の全体記録がある場合は、更新日時の新しいものを採用します。

## 時刻・分割の注意

マークは録画出力のフレーム数をFPSで時間に換算した目安です。エンコーダーの遅延、フレーム落ち、分割時の内部バッファーによるずれを補正する機能はありません。重要な場面は前後を再生して確認してください。

OBSのファイル分割通知を受けると、分割後の動画を新しい記録対象として追跡します。ファイル内時刻と録画全体の時刻を保存しますが、**分割境界の時刻は推定**です。前後の確認範囲が境界をまたぐ場合、閲覧ツールは同一ファイル内の範囲だけを再生し、隣の動画も確認するよう表示します。

録画途中にスクリプトを追加・再読み込みした場合、既に分割された動画の開始時刻を確定できません。分割設定が有効な録画では、そのファイルのマークはファイル内時刻を「不明」とし、録画全体の時刻だけを保存します。次に観測した分割から、ファイル内時刻の推定を再開します。録画前に導入しておくのがおすすめです。

通常のOBS録画以外、リプレイバッファー、配信のみ、複数の録画出力を作る別拡張、特殊なFFmpeg出力、録画後の自動改名・移動は対象外です。OBSの再多重化や動画の改名後も元のファイル名を記録するため、関連付けの修正が必要になります。

## 最初の確認（1分程度）

1. 10秒ほど録画し、見せ場キーを1回押します。
2. 一時停止中に同じキーを押して、マークが増えないことを確認します。
3. 再開後、説明キーを押して録画を終了します。
4. 動画の隣にJSONができていることを確認し、閲覧ツールで2件の位置を確認します。
5. 分割を使う場合は、OBSの分割設定を有効にした短い録画で、分割前後にマークを付けて確認します。

キーがゲーム中に反応しない場合は、ゲームのキーとの重複と、OBSの「設定 → 詳細設定 → ホットキー」のフォーカス設定を確認してください。OBSとゲームの権限差も影響する場合があります。

## 保存失敗時

保存先の空き容量・書き込み権限を確認し、「保存を再試行」を押してください。保存失敗したマークは、スクリプトが動いている間はメモリに保持します。保存できないままOBSを終了すると、未保存分を失う場合があります。

前の録画に未保存マークがある場合は、上書きして消さないよう次の記録開始を止めます。保存を直して再試行し、録画中であれば次にマークを付けると途中記録として再接続します。OBSを異常終了した場合は、最後に成功した保存分までが残ります。

## EditAssistとの関係

このパッケージは独立したOBS用拡張です。既存のEditAssistを変更していません。JSON形式を公開しているので、今後EditAssist側に読み込み機能を追加して、前後のプレビュー・カット・台本制作へつなげられます。現在は同梱の閲覧ツールで確認してください。
