# PreviewLite 0.3.0（実験版）

EditAssistとは別のYMM4用プラグインです。**YMM4 4.56.1.1 / .NET 10専用**。
動画全編のプロキシを作らず、プレビューの更新・描画頻度を抑える方式を試します。
確実な速度改善や、切替・トランジションの引っかかり解消は保証しません。

## 導入・試す手順

1. 作業を保存し、YMM4を終了します。
2. 旧PreviewLiteがある場合は、旧版のフォルダーを **user/pluginの外へ退避** します。フォルダー名を変えるだけでは無効になりません。EditAssistなど他のプラグインはそのままです。
3. `PreviewLite-0.3.0-net10.ymme` を開いて導入し、YMM4を再起動します。
4. メニュー「ツール」から「PreviewLite：軽量プレビュー（試作）」を開きます。プレビュー軽量化の初期状態はOFFです。
5. 本番プロジェクトのコピーを開き、「通常状態を計測」で重い区間を再生します。
6. 「軽量化をON」（初期選択：再生20fps／停止・編集10fps）にして、同じ区間を再生します。
7. 音声と映像のずれ・体感・待機延長回数を比較します。まだ重ければ再生15fpsを試してください。
8. 「OFF・通常に戻す」か、このツールを閉じれば通常動作に戻ります。

設定変更後はもう一度ONを押して適用します。設定をディスクには保存せず、YMM4起動時は毎回OFFです。
接続済みでも「観測描画」がずっと0なら、YMM4を再起動してから試してください。
すでに動作しているプレビュー処理では、最適化された呼出しに起動後の変更が適用されないことがあります。

ProxyForgeを使わず比較する場合は、YMM4を終了し、ProxyForgeフォルダーを**user/pluginの外へ**退避してください。
キャッシュや素材は消す必要はありません。HighSpeed動画読み込みやEditAssistはそのままで構いません。
他のプレビュー調整（特にPreviewEnhancer）との併用は避けてください。検出できる内部処理の競合は動作を停止します。

## 機能の分担

PreviewLiteはプレビュー軽量化・計測だけのプラグインです。動画参照の変更・警告・読み込み検査はEditAssist 0.3.0の「動画参照・警告」へ移しました。PreviewLiteからプロジェクト編集や動画検査を行いません。

## プレビュー軽量化の範囲

- プレビュー映像の再生中は15／20／30fps、停止・編集時は5／10／15fpsを目安に更新頻度を抑えます。
- 軽量化ON／OFFは音声の再生処理、プロジェクトFPS・解像度、素材パス、アイテム、エフェクト、書き出し設定を変更しません。素材パスの変更機能はありません。
- プロキシ生成、元動画の変換、RAMへの動画全編キャッシュ、画質低下、先読みデコードはしません。
- 1フレームの処理量そのものは減らさないため、デコードが非常に重い場合や切替の待ち時間には効かない可能性があります。
- 更新頻度低下により、映像の滑らかさや停止中のマウス操作の反応は低下します。
- 計測表示はCPU側の描画前（操作反映・映像更新・準備）／描画呼出しの時間と頻度です。映像更新単独の時間、GPU完了時間、実際の画面表示FPSではありません。
- 動画書き出し用の共通ソースやTask.Delay全体は変更せず、編集プレビュー専用のEdit入口とDraw計測だけを対象にします。
  音声クロックから映像時刻を取得する前に更新間隔を空けます。YMM4自身の待機・エラー復旧ループは変更しません。
  実機での書き出し比較は未確認なので、初回は短い動画をOFF／ONで出力して比較してください。

## 問題があった場合

まずOFFにし、改善しなければYMM4を終了し、PreviewLiteの導入フォルダーを`user/plugin`の外へ退避して再起動してください。
内部APIを使う実験版です。YMM4更新後は対応版の確認・修正が必要です。確認済みのバージョン・処理コードが違う場合は停止します。
デバイス復旧時の待ち時間やYMM4自身のエラー処理は維持します。

## ソースからビルド

Windowsと.NET 10 SDKが必要です。YMM4のDLLは配布しません。

```powershell
.\Build.ps1 -Ymm4Directory 'C:\path\to\YukkuriMovieMaker_v4'
```

`artifacts/PreviewLite-0.3.0-net10.ymme` ができます。自動インストールはしません。
Harmony 2.4.2（net10.0版）をvendorに同梱。SHA-256をビルド時に確認します。
検証範囲は [VALIDATION.md](VALIDATION.md)、依存ライブラリは [NOTICES.md](NOTICES.md) を参照してください。
